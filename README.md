# 石橋研 OB・OG会 幹事ノート

石橋研OB・OG会の幹事の仕事を支援するWebアプリ（試作版）。

## 機能
- 幹事年の自動判定（卒業年を5で割った余り）
- OB会（9月中旬）・懇親会（12月中旬〜下旬）のタスクテンプレートと進捗管理
- 出欠の回答と集計
- 引き継ぎノート（会場、案内文、反省など）

## ファイル
- `index.html` : アプリ本体（1ファイル完結）

## 補足
共有データ（タスク・出欠・ノート）は Claude のアーティファクト基盤の `db` 機能に保存されます。
このリポジトリ単体で配信するには、データ保存先（Firebase、Supabase など）への置き換えが必要です。
